# Maximus

### CS2 plugins, community tools, and a lot of C#.

I'm Obaida. I run **Ras El Hanout DZ**, a Counter-Strike 2 community, and work on the plugins, panels and tools behind it.

I got into programming through Minecraft plugins. These days, most of my work is C# and server tooling: saving player progress, getting a menu to behave, or figuring out what broke after an update. Player feedback gives me plenty to work on.

## Ras El Hanout DZ

**The project I spend most of my time on.**

An Algerian CS2 community with custom gameplay and its own web tools. I look after the server, adapt plugins to fit the community, and build the features around them.

My work here includes Cartel progression, saved loadouts, graffiti, VIP integration and admin tools. A lot of it happens behind the scenes: permissions, database changes, backups and keeping things working across maps and updates.

> The players are usually the first to tell me when something needs another pass.
