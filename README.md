## What I Build

I work mostly on systems that become important when the server is full: commands that do not break, data that saves correctly, admin tools that are fast to use, and plugins that survive real player behavior.

My work is not only code. I handle the full chain: Linux setup, Pterodactyl servers, MariaDB schemas, plugin logic, web panels, migrations, backups, and the small config details that decide if a server feels good or annoying.

## Engineering Projects

| Project | What It Does | Stack | Status |
| --- | --- | --- | --- |
| **Ras El Hanout DZ** | Algerian CS2 community server that grew from a local setup into a serious public server. I manage the server architecture, custom systems, database structure, migrations, admin workflow, and performance tuning. | `C#` `CSS#` `MariaDB` `Linux` | Live |
| **RasElHanout AntiDLL** | Anticheat and admin-review tooling focused on suspicious behavior, confidence scoring, and reducing false positives. | `C#` `CounterStrikeSharp` | Active |
| **RasElHanout Duel** | 1v1 duel system built for fast challenges, clean arena flow, and community use without needing admins to babysit every round. | `C#` `CSS#` | Active |
| **WeaponPaints Suite** | Weapon skin ecosystem with MariaDB sync, player loadouts, menu flow, and web integration for skins, gloves, knives, agents, music, and stickers. | `C#` `MariaDB` `PHP` | Active |
| **RasElHanout Graffiti** | Website-linked graffiti selector with saved player slots and in-game commands. Built to feel simple for players, not only admins. | `C#` `MariaDB` | Public |
| **Old Reload System** | Small CS2 gameplay plugin that restores older reload behavior for servers that prefer that feel. | `C#` `CSS#` | Public |
| **PS4 Lounge Manager** | Offline Flutter app for a physical gaming lounge: console sessions, match counters, timers, history, and daily workflow. | `Flutter` `Dart` | Deployed |
| **Community Web Panel** | Laravel/PHP tools for player management, skins, admin panels, stats, and server-connected pages. | `PHP` `Laravel` `MariaDB` | In Progress |
