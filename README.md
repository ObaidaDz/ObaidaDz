## What I do

I work on the parts of a project that people notice only when they are broken:

- game server architecture
- custom C# systems for Counter-Strike 2
- MySQL-backed player data and admin tools
- VPS setup, migration, and performance tuning

Most of my work is not about making something look loud. It is about making it feel clean,
fast, and reliable when people are actually using it.

## Main work

### Ras El Hanout DZ

**Role:** Owner & Lead Developer  
**Type:** Counter-Strike 2 community server

Ras El Hanout DZ started as a local setup and grew into a serious CS2 community, reaching the
**49th global rank**. I handle the server architecture, database structure, custom systems,
hardware migrations, routing decisions, and player-facing features.

What I built and maintained there:

- custom RasElHanout AntiCheat logic
- RasElHanout Duel gameplay system
- database-backed player systems
- server migrations for better routing and lower latency
- moderation and admin workflows
- stable configs for competitive server behavior

---

### Custom 3D Sticker Editor

**Role:** Web Developer  
**Type:** Web-based 3D customization tool

A player-facing tool built for the community website. It lets players customize weapon stickers
with a more realistic preview before using their setup in-game.

Highlights:

- real-time 3D preview
- sticker scaling and positioning
- saved position loading
- interface designed for players, not only admins

---

### PS4 Manager Application

**Role:** Mobile Developer  
**Type:** Gaming lounge management app

A cross-platform Flutter app made for daily gaming lounge operations. The goal was simple:
track sessions accurately and make the business easier to manage.

Highlights:

- match count tracking
- playtime monitoring
- cleaner session history
- practical workflow for a physical gaming lounge
