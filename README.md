<a id="about"></a>
<h2>I'm Obaida. Most people call me Maximus.</h2>

<p>I'm a developer from <strong>Aflou, Laghouat, Algeria</strong>. I learned through my own projects, starting with Java and Minecraft plugins. I wanted to understand how a command, an event or a small change in the code could change what happened inside a game. That curiosity is still what keeps me interested.</p>

<p>These days, most of my work is around <strong>CS2, C# and CounterStrikeSharp</strong>. I run Ras El Hanout DZ and work on the plugins, web panels and server tools around the community. Some days that means adding a gameplay feature. Other days it means tracing a permission issue, fixing saved player data or getting a web page and a plugin to agree.</p>

<p>I like projects where I can see how people use what I've made. Player progression, game economies, cosmetics and practical admin tools are the things I keep coming back to. I also enjoy the smaller fixes: a menu that makes sense, a setting that survives a map change, or a feature that quietly does its job.</p>

<h2>Before CS2, and outside it</h2>

<h3>Minecraft and Nexus</h3>

<p>Minecraft was my starting point. Working with <strong>Java and Spigot</strong> introduced me to commands, event listeners and the systems behind a multiplayer server. <strong>Nexus</strong>, a faction project, gave me room to explore economies and player progression. Those interests carried over into my CS2 work.</p>

<h3>PS4 Lounge Manager</h3>

<p>With <strong>Dart and Flutter</strong>, I worked on an offline app for managing gaming lounge sessions: timers, match counters and session history. It is a different kind of project from a game plugin, but the appeal is similar: making a tool useful to the person who has to use it every day.</p>

<br>

<h2>What matters to me when I build</h2>

<ul>
  <li><strong>Player experience.</strong> Clear controls, readable menus and features that fit the game.</li>
  <li><strong>Keeping progress.</strong> Saved choices and permissions should still make sense after a reconnect or a map change.</li>
  <li><strong>Balance.</strong> More effects and more features do not automatically make a server more enjoyable.</li>
  <li><strong>Maintenance.</strong> Testing, backups and a way to recover belong in the work too.</li>
</ul>
